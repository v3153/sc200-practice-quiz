# SC-200 Practice Quiz

An interactive, browser-based practice quiz for the Microsoft **SC-200: Security Operations Analyst Associate** certification exam. 260+ scenario-based questions covering the full skills-measured surface, with category filters, difficulty tagging, study and exam modes, and a scored breakdown by domain.

**[Try it live →](https://v3153.github.io/sc200-practice-quiz/)** 

## What's covered

Questions are grouped into nine practical categories, chosen to map more closely to how the exam actually tests than Microsoft's broad three-domain outline:

- Automation for Defender XDR + Sentinel
- Responding to alerts in Defender XDR
- Detecting threats via the Sentinel platform
- Responding to alerts in Defender for Endpoint
- Investigating M365 activity (Purview / audit / Graph)
- Threat hunting with KQL + Defender XDR hunting
- Data ingestion into Sentinel
- Sentinel SIEM / platform configuration + RBAC
- Configuring detections + MITRE ATT&CK mapping

## Features

- **Study mode** — see the explanation immediately after answering each question
- **Exam mode** — score is revealed only at the end, for realistic timed practice
- **Filters** — narrow by category and/or difficulty (hard / medium)
- **Shuffle** — randomize question order to avoid memorizing sequence
- **Keyboard shortcuts** — `1–4` to select an option, `Enter`/`→` to advance, `?` to reveal the answer in study mode
- **Scored breakdown** — see your accuracy by category at the end of each run, plus a review-incorrect-only mode
- **No backend required** — a single self-contained HTML file; progress is stored locally in your browser

## Usage

Just open `index.html` in any modern browser, or use the [live version](https://v3153.github.io/sc200-practice-quiz/) hosted via GitHub Pages. No installation, build step, or dependencies.
